Portfolio Optimisation Dashboard

Built an interactive Portfolio Optimisation Dashboard applying Modern Portfolio Theory and Monte Carlo simulation to construct efficient frontiers and optimise asset allocation. The web application enables users to upload historical market data and analyse portfolio risk, returns, Sharpe ratios, correlations, drawdowns and diversification through an intuitive browser-based interface. Developed using HTML, CSS and JavaScript with interactive data processing and visualisations.

Data Requirements

The dashboard accepts historical daily market data in Excel (.xlsx) or CSV (.csv) format. Upload a dataset containing a Close price column for each asset, which is used to calculate returns, optimise portfolio allocations and generate portfolio analytics.

How to Use
Upload the Portfolio_Example file to the dashboard.
Ensure the dataset contains daily closing prices for each asset.
Review the generated portfolio analytics, efficient frontier and optimisation outputs.
